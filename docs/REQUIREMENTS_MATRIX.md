# Матрица соответствия заданию Марка

Источник — оригинальный DOCX «Задание Марк», основной текст. «Абз.» означает номер абзаца в `word/document.xml` при нумерации с единицы, включая пустые. Повторная сверка выполнена по исходному файлу. Шкала преподавателя включает пять критериев по 0–2 балла, максимум 10. Балл назначает преподаватель на защите.

Цель задания по абз. 30 — групповой MVP коммуникационного продукта с применением готовых инструментов ИИ. Тема и данные согласуются. Строки 01–16 составляют матрицу обязательных условий. Последние строки фиксируют проверку критериев оценки.
