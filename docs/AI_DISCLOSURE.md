# Использование ИИ и вклад команды

В исходном README задекларирована помощь OpenAI Codex в коде исходного прототипа, синтетических данных, расчётах и материалах. В v2 OpenAI Codex изучил задание, воспроизвёл исходные расчёты, реализовал предложенные изменения, подготовил синтетические сценарии, написал тесты, оформил документацию и слайды. В Git изменения v2 записаны от имени OpenAI Codex. Модель внутри приложения работает на scikit-learn без генеративного API.

Преподаватель требует существенной доработки и осознанного вклада студентов, ссылки на источники заимствований и декларации использования генеративного ИИ. Наличие кода, отчёта и слайдов не подтверждает личный вклад участника. Команда проверяет технические решения на новых примерах, вносит существенные собственные правки по итогам проверки, фиксирует решения в Git и самостоятельно рассказывает о них на защите.

| Заполняет участник |  |  |  |
| Заполняет участник |  |  |  |

Кандидаты для самостоятельной работы команды описаны в [PILOT.md](PILOT.md). Замеры, согласования, источники данных и вклад участников отражайте по факту. Два источника по библиотеке указаны в [ML_EXPERIMENT.md](ML_EXPERIMENT.md). Скриншот в презентации снят с локального интерфейса на демонстрационных данных.
