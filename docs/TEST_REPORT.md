Набор Python использует временные базы и локальные порты. В тесте SQLite-сценария HTTP-сервер останавливается и создаётся заново. Дополнительная проверка двумя последовательными процессами `app.py` подтвердила сохранность карточки, решения, истории и аналитики. Браузерный тест запускает приложение отдельным процессом и удаляет временную БД после окончания.

Для отдельного запуска браузерной проверки нужны Node.js 20+ и Playwright. Установленный Chrome можно указать в `CHROME_PATH`, путь к модулю Playwright в `PLAYWRIGHT_MODULE` и путь к нужному Python в `APP_PYTHON`. Когда модуль Playwright и его браузер установлены, достаточно `node tests/browser.mjs`. Дополнительные зависимости нужны только для этой проверки.

На Mac во время установки пришлось исключить некорректную локальную настройку прокси только для процесса pip. Проверка после установки использовала loopback. Windows, Linux, Safari, Firefox, живые операторы и промышленная нагрузка в этой сессии не проверялись. Формальная проверка доступности по WCAG и оценка безопасности для публикации не проводились.
